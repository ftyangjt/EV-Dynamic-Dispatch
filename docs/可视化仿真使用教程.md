# 可视化仿真使用教程

本文档简要说明如何在本仓库中启动可视化仿真，并查看不同调度策略在电动车配送场景下的运行效果。

## 1. 适用内容

当前仓库提供两种可视化方式：

- Matplotlib 动画：
  适合快速播放一次仿真过程，或导出 GIF / MP4 动画文件。
- Streamlit 仪表盘：
  适合交互式查看任务趋势、车辆电量变化和路网快照。

## 2. 环境准备

建议先进入项目根目录，再安装依赖：

```bash
pip install -r requirements.txt
```

如果你的机器上有多个 Python 环境，建议显式使用同一个解释器执行后续命令。例如在 Windows 上：

```powershell
C:\Users\lhxsy\anaconda3\python.exe -m pip install -r requirements.txt
```

## 3. 启动 Matplotlib 动画

最常用的方式是直接运行主入口并开启 `--visualize`：

```bash
python -m ev_dispatch.main --visualize --steps 20 --tasks-per-step 3
```

含义如下：

- `--visualize`：
  启用 Matplotlib 动画播放。
- `--steps`：
  仿真步数。每一步会生成新任务并执行调度。
- `--tasks-per-step`：
  每一步生成的任务数量。

当前主入口会同时运行三种策略并打印结果：

- `nearest`
- `largest`
- `composite`

如果只想播放某一种策略的轨迹，可以使用：

```bash
python -m ev_dispatch.main --visualize --visualize-strategy composite
```

可选值为：

- `nearest`
- `largest`
- `composite`

## 4. 导出动画文件

如果不想弹出图窗，而是直接导出动画，可以运行：

```bash
python -m ev_dispatch.main --visualize --visualize-strategy composite --save-animation outputs/demo.gif --no-show
```

说明如下：

- `--save-animation outputs/demo.gif`：
  将动画保存到 `outputs/` 目录。
- `--no-show`：
  不弹出 Matplotlib 窗口，只执行导出。

支持导出：

- `.gif`
- `.mp4`

如果导出 MP4 失败，通常是本机没有可用的视频写入器；此时优先使用 GIF。

## 5. 启动 Streamlit 仪表盘

在项目根目录运行：

```bash
streamlit run ev_dispatch/visualization/streamlit_dashboard.py
```

如果 `streamlit` 命令不可用，也可以这样启动：

```bash
python -m streamlit run ev_dispatch/visualization/streamlit_dashboard.py
```

启动后，终端会显示本地访问地址，通常是：

```text
http://localhost:8501
```

在浏览器打开该地址即可。

## 6. Streamlit 页面能做什么

当前仪表盘支持：

- 选择场景规模：
  小规模 / 中规模 / 大规模
- 选择算法模式：
  仅最近优先 / 仅最大优先 / 仅综合评分 / 三策略对比
- 设置仿真步数
- 设置每步任务数
- 设置随机种子
- 选择综合评分预设：balanced / deadline / cost / energy
- 一键运行仿真
- 查看任务状态趋势图
- 查看平均电量趋势图
- 查看策略评分与完成失败对比
- 按 step 查看路网快照
- 自动播放轨迹

Streamlit 仪表盘已经接入 `composite` 策略，可以直接选择单独运行综合评分策略，也可以使用三策略对比。选择不同综合评分预设后，可以观察同一场景下车辆轨迹、完成率和成本指标的变化。

## 7. 推荐的最小体验流程

第一次使用时，建议按下面顺序操作：

1. 运行 Matplotlib 动画，确认环境能正常弹窗：

```bash
python -m ev_dispatch.main --visualize --steps 10 --tasks-per-step 2
```

2. 再运行 `composite` 策略轨迹：

```bash
python -m ev_dispatch.main --visualize --visualize-strategy composite --steps 10 --tasks-per-step 2
```

3. 最后启动 Streamlit 仪表盘做交互式查看：

```bash
streamlit run ev_dispatch/visualization/streamlit_dashboard.py
```

## 8. 常见问题

### 8.1 `ModuleNotFoundError: No module named 'numpy'`

说明当前运行的 Python 解释器没有安装依赖。请确认安装依赖和运行程序使用的是同一个 Python 环境。

### 8.2 Matplotlib 图窗没有弹出

常见原因：

- 当前环境不支持图形界面
- 使用了 `--no-show`
- 远程终端或无桌面环境

这种情况下建议直接导出 GIF：

```bash
python -m ev_dispatch.main --visualize --save-animation outputs/demo.gif --no-show
```

### 8.3 Streamlit 页面打不开

可以检查：

- 终端中是否成功显示本地地址
- 端口是否被占用
- 浏览器是否拦截了本地访问

必要时可显式指定端口：

```bash
python -m streamlit run ev_dispatch/visualization/streamlit_dashboard.py --server.port 8502
```

## 9. 相关入口文件

如果后续要继续扩展可视化，通常也是从这三个文件入手。
